ทำไมเราถึงพัฒนา Node เอง

การซื้อโมดูลสำเร็จจากต่างประเทศมาขาย เจอปัญหาที่แก้เองไม่ได้เต็มไปหมด

ข้อมูลไม่ได้เก็บในไทย — ปัญหาอธิปไตยข้อมูล งานราชการติดขัด
ปรับแก้ตามงานไม่ได้ — ฟีเจอร์ถูกล็อก ทำตามสเปคลูกค้าไม่ได้
สั่งงาน node ตรง ๆ ไม่ได้ — ต้องผ่านระบบของเจ้าของ ควบคุมเองไม่ได้
มี error / bug — ที่เราแก้เองไม่ได้ ต้องรอเจ้าของ
สั่งจำนวนน้อยราคาแพง — MOQ สูง ต้นทุนไม่คุ้ม
และอื่น ๆ — ที่ทำให้เราคุมคุณภาพและอนาคตไม่ได้
เราจึงตัดสินใจ ทำเอง — ค่อย ๆ พัฒนา “ช้าแต่ชัวร์” ให้ใช้งานได้จริง และคุมต้นทุนได้
v1 · LTE

เริ่มจากใส่ซิม สื่อสารผ่านมือถือ

ติดที่ไหนก็คุยได้ · แลกกับค่าซิมรายเดือนทุกต้น + เปลืองพลังงาน

v2 · LoRa

ย้ายมา LoRa ระยะไกล กินไฟต่ำ

ไม่มีค่าซิมรายต้น เหมาะวางทั้งเมือง · ต้องมี gateway

v3 · Universal

LTE + LoRa ในตัวเดียว — มีทางสำรองเสมอ

สลับอัตโนมัติตามพื้นที่ ไม่มีจุดบอด

AC → Solar

เตรียมรับ

คำถามที่มักเจอ

“มี supplier smart light อยู่แล้ว”
node เราคุมโคมเจ้าเดิมได้ ไม่ต้องทิ้งของ + ทำสิ่งที่คนเทรดของทำไม่ได้ (dimming ตามสเปค / OTA / telemetry / AI)
“แพงกว่าของนำเข้าไหม”
เราทำเองจึงคุมต้นทุนได้ + ขายส่ง/white label + คิดทั้งอายุงาน (แก้จากออฟฟิศได้ · มอก. ผ่าน audit · ต่อยอดเป็นงานใหม่) = คุ้มกว่า
“ทำเองจริงไหม / เสถียรไหม”
เส้นทาง LTE→LoRa→Universal + demo สด + โคมที่ EGAT เปิด 24 ชม. ในที่ร้อนจัด
“ต้องรื้อกล้องเดิมไหม”
ไม่ต้อง — ต่อหลัง NVR หรือขนานกับของเดิม เริ่มจาก Jetson จุดเดียวก็ได้
“Solar ราคาเท่าไหร่”
กำลังทำ DIALux อยู่ ไม่รับปากตัวเลขที่ยังไม่นิ่ง จะเร่งส่งให้
